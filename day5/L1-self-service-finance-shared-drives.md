# Cannot Access Finance Shared Drive (S:) - Quick Self-Service

If your Finance shared drive (S:) is missing or not opening, your files are usually still safe on the server.

## Try these steps first
1. Save your work, then sign out of Windows.
2. Sign back in and wait 2 full minutes before opening File Explorer.
3. Check This PC for drive S:.
4. If S: is missing, open File Explorer and enter \\finbridge-fs01\Finance in the address bar.
5. If the Finance folder opens, sign out and sign in once more to restore automatic mapping.
6. If S: still does not appear, restart the device once and sign in again.

## What not to worry about
- Your Finance files are still on the shared server.
- This is typically a sign-in mapping issue, not file deletion.

## If you need to contact support
Provide these details so support can fix it quickly:
- Your full name and work login.
- Exact time the problem started.
- What you see: S: missing, red X, or access denied.
- Whether \\finbridge-fs01\Finance opens.
- Whether sign-out/sign-in or restart changed anything.
- Device name (if known) and your location.

Contact IT support if S: remains missing after these steps, or if \\finbridge-fs01\Finance does not open.
