# Cannot Access Finance Shared Drive (S:) - What You Can Do

If your Finance shared drive (S:) is missing or not opening, your files are usually still safe on the server.

## Try these steps first
1. Sign out of Windows, then sign in again.
2. Wait 1 to 2 minutes after sign-in before opening File Explorer.
3. Open File Explorer and check This PC for drive S:.
4. If S: is still missing, in the address bar type \\finbridge-fs01\Finance and press Enter.
5. If the folder opens, close File Explorer and sign out/sign in one more time.
6. If it still does not work, restart your computer once and sign in again.

## What not to worry about
- Your Finance files are not deleted by this issue.
- This is usually a drive mapping or sign-in timing problem.

## If you need to contact support
Please include these details so IT can resolve it faster:
- Your full name and work login name.
- The exact time the issue started.
- What you saw (for example: S: missing, S: shows red X, or access denied message).
- Whether \\finbridge-fs01\Finance opened successfully.
- Whether signing out and back in fixed it.
- Whether one restart fixed it.
- Your computer name (if known) and office/location.

Contact IT support if S: is still missing after these steps, or if you cannot open \\finbridge-fs01\Finance at all.
