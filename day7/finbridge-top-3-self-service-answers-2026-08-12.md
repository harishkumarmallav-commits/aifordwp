## AVD sign-in and account lockout failures
Try signing out fully and signing back in once more, then check that your password is entered correctly and that Caps Lock is off. If you recently changed your password, wait a few minutes and try again.

If it still will not let you in, connect the service desk and share your username, the exact message you see, the time it happened, and how many times you tried so they can help quickly.

## OneDrive missing files and sync errors
First, check OneDrive is open and signed in, then look in the Recycle Bin and the OneDrive website to see if the file is there. If you find the file online, wait a few minutes for it to appear on your device.

If the file is still missing, connect the service desk and share the file name, when you last saw it, what device you are using, and whether it is missing everywhere or only on one device.

## Shared drive access denied (S:/Finance)
Try closing the file you were using and opening the shared drive again after a few minutes. If you are on VPN, disconnect and reconnect once, then try again.

If access still does not work, connect the service desk and share the drive name, the exact message shown, the folder you need, and the time you tried so they can check it fast.
